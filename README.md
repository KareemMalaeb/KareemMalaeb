👋 About Me

I'm a Software Engineer focused on Java, Spring Boot, and microservices — building backend systems that are clean, scalable, and built to last. My day-to-day is about turning real problems into working software: designing services that talk to each other cleanly, keeping code maintainable, and getting the fundamentals of cloud infrastructure right. I'm still early in my journey and treat that as an advantage — every project here is me getting hands-on with a new piece of the stack.

🛠️ Engineering with Purpose

I don't just want code that runs — I want it to hold up. Across this GitHub you'll find backend services built with Java and Spring Boot, a microservices-based digital wallet, and side projects that stretch into Python and automation. Each repo is a rep at the same goal: write software that's clean enough to hand off, fast enough to trust, and structured well enough that the next feature doesn't break the last one.

🌍 Learning in the Open

I build in public on purpose. Documenting a project properly — the why behind a decision, not just the how — is part of the work, not an afterthought. It's how I keep myself honest about what I actually understand, and it means anyone digging through a repo here can follow the reasoning, not just the commits.

🔥 Always Leveling Up

Right now that means going deeper on microservices architecture and cloud fundamentals, but the bigger habit is the constant: I pick a gap in my skills and go build something that forces me to close it. That's why a Spring Boot quiz app sits next to a Python home-automation project and a real-time object detection experiment — different corners of engineering, same instinct to learn by shipping.

✨ Let's Build Something

These repos are a running log of where I've been and where I'm headed, not a finished product. I'm always open to connecting with other engineers, comparing notes, or teaming up on something worth building — reach out if that's you.
